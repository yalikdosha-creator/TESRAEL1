# Tesrael (Preview)

A concept storefront website for Tesla car parts.

## What this includes
- Product catalog with categories and model filters (Model S/3/X/Y/Cybertruck)
- Visible prices for each part
- Cart UI (add/remove/quantity) with subtotal
- Checkout button that shows a "coming soon" message (no real purchasing)

## Run / preview
This is a static site. Open `index.html` directly in a browser, or serve the folder locally:

```bash
# from this folder
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes
- **Name:** "Tesrael" is the current store name.
- **Purchasing:** Online ordering is intentionally disabled for now; the UI is designed to look like a store preview.
- **Trademarks:** Tesla and model names are used for compatibility reference only.
